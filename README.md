# 📖 الباحث في القرآن الكريم

برنامج متقدم ومجاني (مفتوح المصدر) للبحث في القرآن الكريم وتحليل الكلمات المصاحبة (المتلازمات اللفظية)، مع ميزات إحصائية ونحوية متقدمة وتصدير احترافي للنتائج، صُمم خصيصاً لخدمة الباحثين في الدراسات القرآنية واللغوية.

💡 **فكرة المشروع:** د. شعيب يحيى (جامعة سعيدة).

---

## ✨ المميزات الأساسية
### 🔍 1. محرك بحث لغوي متطور
أنماط بحث متعددة: يدعم التطابق التام، البحث الجزئي، تطابق الجمل المتصلة، ونظام (و/أو) للكلمات المتعددة.

البحث الصرفي (بالجذر): إمكانية البحث بجذر الكلمة لاستخراج جميع تصريفاتها ومشتقاتها بناءً على المعجم القرآني (Corpus).

الاستبعاد اللفظي الذكي (Negative Search): فلتر متقدم لاستبعاد كلمات معينة من النتائج مع مطابقة مرنة للتشكيل، مما يمنع "الاستبعاد الجائر" ويفصل بين الكلمات المشتركة لفظياً بحسب حركاتها (مثل التمييز بين حُبّ و حَبّ).

وضع المقارنة المتزامن: إمكانية البحث عن كلمتين معاً ومقارنة انتشارهما، مع إعطاء كل كلمة لوناً مستقلاً (Highlight) داخل الآيات لتسهيل القراءة البصرية.

### 📊 2. التحليل البياني والنحوي
لوحة الإعراب والصرف: استخراج دقيق للأسماء والأفعال وحالاتها الإعرابية للكلمات المبحوثة، مع إمكانية عرض مسار انتشار أي حالة إعرابية على الرسم البياني التفاعلي.

تحليل السياق (الألفاظ المصاحبة): أداة خوارزمية تحسب أكثر الكلمات أو العبارات (الثنائية والثلاثية - N-grams) وروداً قبل وبعد الكلمة المبحوثة، مع تصفية حروف الجر والضمائر، وعرض النتائج في "سحابة كلمات" وجداول مئوية.

الرسم البياني المزدوج: رسم بياني ذكي لانتشار الكلمة مقسماً (حسب ترتيب المصحف) و(حسب ترتيب النزول)، مع تمييز العهد المدني بلون مختلف.

### 💼 3. بيئة عمل الباحث (المحفظة البحثية)
المحفظة المحلية: حفظ واسترجاع جلسات البحث (بما فيها الفلاتر والكلمات المستبعدة) لاستكمال الدراسة لاحقاً دون الحاجة لقواعد بيانات خارجية (اعتماداً على localStorage).

ملاحظات الآيات: إمكانية تدوين ملاحظات وتأملات بحثية مخصصة أسفل كل آية والاحتفاظ بها.

### 💾 4. التصدير الأكاديمي الاحترافي
التقرير الشامل (Word): توليد ملف docx متكامل بضغطة زر يحتوي على (صورة الرسوم البيانية، جداول التلازم اللفظي، إحصاءات الإعراب، الآيات المستخرجة، وملاحظات الباحث). الملف مُهندس برمجياً ليتوافق 100% مع التنسيق العربي (RTL) حتى في الإصدارات القديمة مثل Word 2010.

تصدير إحصائي (Excel): تحميل جداول الإحصاء والمقارنات بصيغة csv.

العمل المكتبي (Offline 100%): يعتمد البرنامج على قاعدة بيانات SQLite مدمجة، ويعمل بالكامل دون أي حاجة للاتصال بالإنترنت.

## 🚀 طريقة التشغيل للمطورين
1. تحميل المشروع: قم بنسخ المستودع إلى جهازك:
   ```Bash
   git clone [https://github.com/chyahia/Quran-Search.git](https://github.com/chyahia/Quran-Search.git)
   cd Quran-Search

2. تثبيت المتطلبات: يفضل إنشاء بيئة وهمية (Virtual Environment) أولاً، ثم تثبيت المكتبات المطلوبة:
   ```Bash
   pip install flask python-docx

3. التشغيل:
   ```Bash
   python app.py
   ثم افتح المتصفح على الرابط: http://127.0.0.1:5555
