# 📖 الباحث في القرآن الكريم

برنامج مجاني مفتوح المصدر للبحث في القرآن الكريم وتحليل ألفاظه صرفيًا ونحويًا وإحصائيًا، مع تحليل الألفاظ المصاحبة وتصدير النتائج في تقارير أكاديمية. صُمّم لخدمة الباحثين في الدراسات القرآنية واللغوية، ويعمل على الجهاز دون اتصال بالإنترنت.

💡 **فكرة المشروع:** د. شعيب يحيى (جامعة سعيدة).

---

## ✨ المميزات

يتكوّن البرنامج من ثلاثة تبويبات.

### 🔍 التبويب 1: البحث اللغوي والإحصائي (قاعدة `quran.db`)

- **أنماط بحث متعددة:** التطابق التام، والبحث الجزئي، وتطابق الجمل المتصلة، والربط بين الكلمات بـ«و» و«أو».
- **البحث بالجذر:** استخراج كل تصريفات الجذر ومشتقاته اعتمادًا على المعجم القرآني (Quranic Arabic Corpus).
- **الاستبعاد اللفظي:** استبعاد كلمات بعينها من النتائج مع مطابقة مرنة للتشكيل تفرّق بين الكلمات المشتركة لفظًا (مثل حُبّ وحَبّ).
- **وضع المقارنة:** البحث عن كلمتين معًا ومقارنة انتشارهما، بلون مستقل لكل كلمة داخل الآيات.
- **لوحة الأسماء والأفعال:** عند البحث بالجذر، تصنيف كل موضع إلى اسم (بحالته الإعرابية) أو فعل (بزمنه، ومعلومًا أو مجهولًا)، اعتمادًا على قاعدة MASAQ. والإحصاء مطابق لنتائج التبويب 2 في كل المواضع.
- **الرسم البياني المزدوج:** انتشار الكلمة بحسب ترتيب المصحف وبحسب ترتيب النزول، مع تمييز العهد المدني.
- **الألفاظ المصاحبة:** أكثر الكلمات والعبارات (الثنائية والثلاثية) ورودًا قبل الكلمة المبحوثة وبعدها، في سحابة كلمات وجداول مئوية.

### 🧩 التبويب 2: البحث النحوي (قاعدة `MASAQ.db`)

- البحث بالجذر أو بالنص، مع فلاتر: الوسم الصرفي، والموقع النحوي، والحالة الإعرابية.
- عرض جذع كل كلمة ووسمه وموقعه وحالته، مع مواءمة ترقيم الكلمات بين القاعدتين.

### 🛠️ التبويب 3: أدوات الفحص (للمطوّرين والمراجعين)

ست أدوات للقراءة فقط، تكشف التعارضات ولا تعدّل شيئًا، ولكل منها تصدير Excel:

1. فحص التماسك الداخلي لقاعدة MASAQ.
2. فحص ربط الجذور بين القاعدتين.
3. مقارنة أعداد مواضع الجذور بين التبويبين.
4. فحص وسم الكلمات ذات الجذور.
5. مقارنة الاسم والفعل مع جدول `morphology`.
6. مقارنة نوع الكلمة (اسم/فعل) بين التبويبين.

### 💼 بيئة عمل الباحث

- **المحفظة المحلية:** حفظ جلسات البحث واسترجاعها، بما فيها الفلاتر والكلمات المستبعدة (عبر `localStorage`).
- **ملاحظات الآيات:** تدوين ملاحظات بحثية أسفل كل آية والاحتفاظ بها.

### 💾 التصدير

- **تقرير Word شامل:** الرسوم البيانية، وجداول الإحصاء، ولوحة الأسماء والأفعال، والألفاظ المصاحبة، والآيات، وملاحظات الباحث، بتنسيق عربي (RTL) متوافق حتى مع Word 2010.
- **تصدير Excel/CSV** للجداول الإحصائية.

## 🚀 التشغيل للمطوّرين

1. **تحميل المشروع:**

   ```bash
   git clone https://github.com/chyahia/Quran-Search.git
   cd Quran-Search
   ```

2. **تثبيت المتطلبات** (يُفضَّل داخل بيئة افتراضية):

   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install flask python-docx openpyxl
   ```

3. **التشغيل:**

   ```bash
   python app.py
   ```

   ثم افتح المتصفح على العنوان: `http://127.0.0.1:5555`

## 📦 بناء نسخة تنفيذية (exe) لنظام Windows

```bash
pip install pyinstaller
pyinstaller --name "Quran_Search" --noconsole --add-data "templates;templates" --add-data "static;static" --add-data "quran.db;." --add-data "MASAQ.db;." app.py
```

### ✏️ تعديلات على قاعدة MASAQ

النسخة المرفقة من `MASAQ.db` **نسخة معدَّلة** من القاعدة الأصلية. أُجريت عليها تصحيحات منهجية في الوسوم الصرفية والمواقع النحوية وأعمدة الإعراب وبنية بعض المقاطع، واستند كل تصحيح إلى مراجع من القاعدة نفسها. وكل تعديل موثّق بقيمه قبل التعديل وبعده في سجل التعديلات داخل مجلد [`docs`](docs/). أما نص القرآن الكريم فلم يُغيَّر فيه شيء.
