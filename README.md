# 📖 الباحث في القرآن الكريم

برنامج مجاني مفتوح المصدر للبحث في القرآن الكريم وتحليل ألفاظه صرفيًا ونحويًا وإحصائيًا، مع تحليل الألفاظ المصاحبة وتصدير النتائج في تقارير أكاديمية. صُمّم لخدمة الباحثين في الدراسات القرآنية واللغوية، ويعمل على الجهاز دون اتصال بالإنترنت.

💡 **فكرة المشروع:** د. شعيب يحيى (جامعة سعيدة).

---

## ✨ المميزات

يتكوّن البرنامج من خمسة تبويبات.

### 🔍 التبويب 1: البحث اللفظي والإحصائي (قاعدة `quran.db`)

- **أنماط بحث متعددة:** التطابق التام، والبحث الجزئي، وتطابق الجمل المتصلة، والربط بين الكلمات بـ«و» و«أو».
- **البحث بالجذر:** استخراج كل تصريفات الجذر ومشتقاته اعتمادًا على المعجم القرآني (Quranic Arabic Corpus).
- **الاستبعاد اللفظي:** استبعاد كلمات بعينها من النتائج مع مطابقة مرنة للتشكيل تفرّق بين الكلمات المشتركة لفظًا (مثل حُبّ وحَبّ).
- **وضع المقارنة:** البحث عن كلمتين معًا ومقارنة انتشارهما، بلون مستقل لكل كلمة داخل الآيات.
- **لوحة الأسماء والأفعال:** عند البحث بالجذر، تصنيف كل موضع إلى اسم (بحالته الإعرابية) أو فعل (بزمنه، ومعلومًا أو مجهولًا)، اعتمادًا على قاعدة MASAQ. والإحصاء مطابق لنتائج التبويب 2 في كل المواضع.
- **الرسم البياني المزدوج:** انتشار الكلمة بحسب ترتيب المصحف وبحسب ترتيب النزول، مع تمييز العهد المدني.
- **أكثر السور ورودًا:** لكل بحث (مطابق أو جزئي أو بالجذر): عدد المواضع والآيات ونسبتها في كل سورة، العشر الأوائل أو كل السور، وقائمتان متجاورتان في وضع المقارنة.
- **الألفاظ المصاحبة:** أكثر الكلمات والعبارات (الثنائية والثلاثية) ورودًا قبل الكلمة المبحوثة وبعدها، في سحابة كلمات وجداول مئوية.

### 🧩 التبويب 2: البحث النحوي والصرفي (قاعدة `MASAQ.db`)

- البحث بالجذر أو بالنص، مع فلاتر تنطبق على **جذع الكلمة**: الوسم الصرفي، والموقع النحوي، والحالة الإعرابية. فالشروط المتناقضة (مثل «فعل ماضٍ» مع «مجرور») لا تعطي نتائج.
- **فلتر «الضمير المتصل بالكلمة»:** فاعل، أو نائب فاعل، أو مفعول به، أو مضاف إليه، أو اسم مجرور، أو اسم إنّ، أو اسم كان. مثال: أفعال ماضية فاعلها ضمير متصل.
- **مجموعتان في الوسم الصرفي:** «كل الأسماء» و«كل الأفعال». و«اسم علم» يشمل العلم الأعجمي (إبراهيم، موسى...).
- **الاختيارات غير المتوافقة باهتة:** الفعل لا يقبل الجر ولا مواقع الأسماء، والاسم لا يقبل الجزم.
- عرض جذع كل كلمة ووسمه وموقعه وحالته وضمائره المتصلة، مع مواءمة ترقيم الكلمات بين القاعدتين.
- **وضع المقارنة** بين بحثين، والتوزيع البياني، و**أكثر السور ورودًا**، ونسخ النتائج.

### 🌳 التبويب 3: ملف الجذر

كل ما يتعلق بجذر واحد في صفحة:

- **الإحصاء العام:** المواضع، والآيات، والسور، والمكي والمدني، وأول ورود بترتيب المصحف وبترتيب النزول.
- **صيغ الجذر المعجمية (اللمّات):** مثل «آمَنَ» و«مُؤْمِن» و«إِيمَان»، مع عدد كل صيغة وأكثر صورها المكتوبة ورودًا، وآيات كل صيغة.
- **الأسماء والأفعال** بتفصيلها، و**التوزيع** على السور (ترتيب المصحف أو النزول، أعمدة أو خط)، و**أكثر السور ورودًا**.
- **الجذور المصاحبة** في نافذة يختارها الباحث (من كلمة إلى خمس كلمات)، مرتبة بعدد المصاحبة أو بقوة الارتباط (الملاحظ ÷ المتوقع). والنقر على جذر يفتح ملفه.
- **مقارنة جذرين:** جدول موازنة، وعدد الآيات التي يجتمعان فيها، وكم مرة يقع أحدهما قرب الآخر، والآيات التي تجمعهما.
- **التصدير:** تقرير Word بتنسيق عربي (RTL)، ونسخ الملف.

### 📊 التبويب 4: الإحصاء العام

- **ترتيب الجذور** بحسب ورودها، مع الآيات والسور والمكي والمدني وعدد الصيغ، وتصفية وترتيب. والنقر على جذر يفتح ملفه.
- **السور:** نسبة الأفعال إلى الأسماء في كل سورة (رسم بياني بترتيب المصحف أو النزول)، وجدول السور قابل للترتيب، وملف لكل سورة: الأسماء والأفعال، وأكثر جذورها ورودًا، والجذور المميِّزة لها (الأكثر ورودًا فيها من نصيبها المتوقع).
- **المكي والمدني:** جدول موازنة، وأكثر الجذور ورودًا في كل منهما، والجذور الأميل إلى أحدهما، والجذور التي لم ترد إلا في أحدهما.
- **التصدير:** ملف Excel بخمس أوراق، ونسخ القسم المعروض.

### 🛠️ التبويب 5: أدوات الفحص (للمطوّرين والمراجعين)

ست أدوات للقراءة فقط، تكشف التعارضات ولا تعدّل شيئًا، ولكل منها تصدير Excel:

1. فحص التماسك الداخلي لقاعدة MASAQ.
2. فحص ربط الجذور بين القاعدتين.
3. مقارنة أعداد مواضع الجذور بين التبويبين.
4. فحص وسم الكلمات ذات الجذور.
5. مقارنة الاسم والفعل مع جدول `morphology`.
6. مقارنة نوع الكلمة (اسم/فعل) بين التبويبين.

### 💼 بيئة عمل الباحث

- **المحفظة المحلية:** حفظ جلسات البحث واسترجاعها، بما فيها الفلاتر والكلمات المستبعدة (عبر `localStorage`).
- **ملاحظات الآيات:** تدوين ملاحظات بحثية أسفل كل آية والاحتفاظ بها.

### 💾 التصدير

- **تقرير Word شامل** للبحث اللفظي: الرسوم البيانية، وجداول الإحصاء، ولوحة الأسماء والأفعال، والألفاظ المصاحبة، والآيات، وملاحظات الباحث، بتنسيق عربي (RTL) متوافق حتى مع Word 2010.
- **تقرير Word لملف الجذر** (أو لمقارنة جذرين) بالتنسيق العربي نفسه.
- **تصدير Excel/CSV** للجداول الإحصائية، ولـ«الإحصاء العام».

## 🚀 التشغيل للمطوّرين

1. **تحميل المشروع:**

   ```bash
   git clone https://github.com/chyahia/Quran-Search.git
   cd Quran-Search
   ```

2. **تثبيت المتطلبات** (يُفضَّل داخل بيئة افتراضية):

   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install flask python-docx openpyxl
   ```

3. **التشغيل:**

   ```bash
   python app.py
   ```

   ثم افتح المتصفح على العنوان: `http://127.0.0.1:5555`

## 📦 بناء نسخة تنفيذية (exe) لنظام Windows

```bash
pip install pyinstaller
pyinstaller --name "Quran_Search" --noconsole --add-data "templates;templates" --add-data "static;static" --add-data "quran.db;." --add-data "MASAQ.db;." app.py
```

### ✏️ تعديلات على قاعدة MASAQ

النسخة المرفقة من `MASAQ.db` **نسخة معدَّلة** من القاعدة الأصلية. أُجريت عليها تصحيحات منهجية في الوسوم الصرفية والمواقع النحوية وأعمدة الإعراب وبنية بعض المقاطع، واستند كل تصحيح إلى مراجع من القاعدة نفسها. وكل تعديل موثّق بقيمه قبل التعديل وبعده في سجل التعديلات داخل مجلد [`docs`](docs/). أما نص القرآن الكريم فلم يُغيَّر فيه شيء.

وأُضيف إلى `quran.db` جدول `word_lemmas` (الصيغة المعجمية لكل كلمة)، مستخرجًا من ملف المدونة القرآنية بالسكربت `build_lemmas.py`، دون تعديل أي جدول موجود. وقد طوبق ترقيم كلماته مع جدول الجذور، وتطابقت جذوره معه في كل المواضع.
